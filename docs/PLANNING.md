# 집앤드 기획 요약

> 원본: `집앤드 기획문서.pdf` (웹앱 서비스 기획서 v1.0, 2026년 10월, 가칭 "중개파트너 AI")
> 가격·KPI·일정은 검증 전 가설이다.

## 1. 한 줄 정의
공인중개사의 임장, 매물 관리, 고객 상담, 공부서류 검토, 계약 준비 등 반복 업무를 AI로 보조하는 부동산 전문 업무 비서 SaaS.

## 2. 제품 원칙
- 모바일 현장 업무 우선 설계 (현장: 사진·음성·체크리스트 / 사무실: 상세 입력·문서 검토)
- AI 결과는 사용자가 검토·수정·확정한다
- 원본 서류와 AI 해석을 구분하고, 중요한 추출값에 원문 근거를 연결한다
- 고객 정보와 매물 정보는 권한에 따라 분리한다
- AI가 법률적 판단을 확정적으로 대체한다고 표현하지 않는다
- 위험 신호는 색상만으로 결론 내리지 않고, 근거 문구와 다음 확인 행동을 함께 제공한다

## 3. 타겟
| 타겟 | 페인포인트 | 우선순위 |
| --- | --- | --- |
| 개업 초기 중개사 | 실무 절차 낯섦, 계약 준비 부담 | 최우선 |
| 1인 중개사무소 | 기록 분산, 반복 입력 | 최우선 |
| 소규모 사무소 | 업무 표준화, 인수인계 | 2순위 |
| 숙련 중개사 | 반복 문서 작성 | 2순위 |

## 4. 기능 우선순위
- **P0 (MVP)**: 회원가입·중개사 인증, 매물 등록·검색, 사진·음성 임장 기록, AI 임장 정리, 공부서류 업로드·OCR, 원문 근거·위험 신호, 고객용 브리핑 PDF
- **P1**: 고객·상담 관리, 특약 라이브러리·실무 사전, 통화 파일 요약, 계약서·확인설명서 초안
- **P2**: 튜토리얼·커뮤니티·공동중개, 일반 소비자용 서비스
- **MVP 제외**: AI 최종 법률 안전 판정, 사용자 확인 없는 계약서 확정·전송, 자동 통화 녹음 보장, 무단 데이터 대량 수집, 전국 공동중개 네트워크

## 5. IA (메뉴 구조)
- **대시보드**: 오늘의 업무, 최근 매물, 진행 중 거래, 검토 대기 문서, AI 사용량. 상단 CTA: 매물 등록 / 임장 기록 / 문서 분석
- **매물 관리**: 목록(필터: 거래유형, 매물유형, 지역, 가격, 상태, 등록일, 담당자, 고객 연결), 등록, 상세, 스마트 임장장, 변경 이력, 고객용 브리핑
- **고객 및 상담**: 고객 목록·상세, 상담 기록, 조건 관리, 추천 매물, 후속 일정
- **AI 문서 분석**: 업로드, 진행 상태, 등기사항증명서, 건축물대장, 결과 비교, 확인 항목, 분석 이력
- **계약 준비**: 거래 체크리스트, 특약 라이브러리, 계약서·확인설명서 초안
- **AI 실무 도우미**: 실무 질문, 법령·지침 검색, 답변 근거
- **구독 및 설정**: 요금제, 결제, 사무소·직원 권한, 알림, 개인정보
- **관리자**: 회원 인증, 결제, AI 비용, 품질, 감사 로그 등

## 6. 핵심 사용자 흐름
- **첫 매물 등록**: 회원가입 → 중개사 인증 → 사무소 정보 → 대시보드 → 매물 등록 → 사진·음성 입력 → AI 추출 → 검토 → 저장 → 브리핑/문서 분석 (목표 5분 이내)
- **공부서류 분석**: 매물 상세 → 업로드 → 종류 확인 → OCR·항목 추출 → 확인 항목 생성 → 원문 대조 → 검토 → 저장 → 계약 체크리스트 반영. 실패 시 원인 + 재업로드/보정/수동 입력 대안
- **상담 기록**: 고객 선택 → 메모/파일 업로드 → 조건 추출 → 고객·매물 연결 → 검토 → 후속 일정

## 7. 주요 기능 메모
- **스마트 임장장**: 사진, 음성(STT), 텍스트 메모, 선택적 위치, 시설 체크리스트, AI 정리(방향·채광·수리·입주 가능일), 구두 안내 출처 표시, 오프라인 임시 저장
- **AI 문서 분석 표시 항목**: 소유자 정보(원문 대조), 근저당권(권리관계 확인), 압류·가압류(전문가 검토), 위반건축물(대장 원문 확인), 발급일(최신 여부 확인)
- **고객 브리핑**: 사진, 금액, 면적, 중개사 설명, 장점, 추가 확인 사항, 연락처. 내부 메모·개인정보 비공개 미리보기
- **특약 추천**: 전세자금대출, 반려동물, 근저당 말소, 잔금·인도, 수리·원상회복, 관리비 정산

## 8. 데이터 모델 (초안)
User, BrokerageOffice/OfficeMember, Property/PropertyVisit, PropertyMedia, Customer/Consultation, Document/DocumentAnalysis, ExtractedField/Evidence(페이지·문구·좌표), ContractWorkspace/DocumentTemplate, Subscription/UsageLedger, AuditLog

## 9. 기술 아키텍처 (권장)
웹앱/PWA(Next.js + TS) → Node.js API(모듈형 모놀리식) → PostgreSQL · S3 호환 스토리지 · 작업 큐(Redis) → AI 워커(OCR·STT·LLM). 위험 신호는 규칙 엔진 + LLM 보조, 실무 Q&A는 RAG.

## 10. 요금제 (가설)
Free 0원 / Basic 19,000원 / Pro 39,000원 / Office 79,000원~ / Enterprise 협의

## 11. 로드맵
Phase 0 검증(2~4주) → Phase 1 MVP(6~10주) → Phase 2 유료화 → Phase 3 계약 보조 → Phase 4 협업 → Phase 5 확장

## 12. KPI (가설)
7일 내 매물 등록 60%+, 첫 매물 등록 중앙값 5분 이내, 주간 활성 35%+, 문서 분석 성공률 90%+, 유료 전환 5~10%, 월 이탈 5% 이하
